# v0.9 — Real API Foundation

Added Node/Next.js API routes backed by SQLite.

## Endpoints
- GET/POST `/api/events`
- GET/POST `/api/activities`
- GET/POST `/api/events/:id/registrations`
- POST `/api/auth/login`

Development accounts are seeded automatically.

## Security note
The login route still uses the agreed development password and does NOT represent production authentication. Before real deployment, passwords must be individually hashed and sessions must be server-issued and protected.

## Next
v1.0 will replace the current UI's localStorage event/activity operations with these APIs and then add proper session authentication.
