# v1.0 — Shared App

The Founder and Member event/activity screens now call the SQLite-backed API instead of the browser localStorage store.

Shared flow:
Founder creates event → server stores event → published event appears on Member side → member registration is written to server → Founder can retrieve registrations.

Development note:
The current member username is still a fixed development value (`aditya`) and authentication is not production-ready. v1.1 should implement secure sessions and use the signed-in user's identity.
