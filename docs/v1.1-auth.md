# v1.1 — Secure Account Foundation

- Server-side sessions stored in SQLite
- HTTP-only session cookie
- Password hashing with Node scrypt
- Login, current-user and logout endpoints
- Server-side role check for event creation
- Event registration uses the signed-in user's identity

Development accounts are seeded using `ASSEMBLY_DEV_PASSWORD` (defaulting to the existing development password only for development). Production must use individual credentials and the development fallback must be removed.
