# v1.3 — Organizer Permissions

Founder can now control granular Organizer permissions.

Permission groups:
- Events
- Participants
- Activities
- Members
- Achievements
- Announcements
- Gallery

Founder always has full access.
Organizers only receive explicitly enabled permissions.
Members never receive Organizer permissions through this system.

Server APIs enforce permissions; UI toggles are only a control surface.
