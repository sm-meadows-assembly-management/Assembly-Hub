# v0.8 — Database Foundation

Assembly now includes a real, portable SQLite database foundation.

## Data model
Users → Events → Registrations
Activities ↔ Events

## Important
The existing browser localStorage demo remains intact so the current UI is not broken.
The SQLite layer is the foundation for shared multi-device data.
