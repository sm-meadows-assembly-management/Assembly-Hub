# v1.4 — Members Management

Founder member-management screen added.

Capabilities:
- Search Assembly members
- View username, role, member-since date, bio and avatar
- Edit display name, profile bio and avatar
- Promote a Member to Organizer or return an Organizer to Member
- Founder account is protected from this editor

Member profile API:
- Signed-in members can edit their own display name, bio and avatar
- Role, permissions and security credentials are not profile-editable

Member management API:
- Founder always allowed
- Organizer requires `members.manage`
- Members cannot manage other accounts
