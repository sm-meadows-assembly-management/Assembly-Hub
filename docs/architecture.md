# Assembly Architecture

Assembly is designed as a private community PWA with a public information site.

## Roles
- Founder — Tuhin; full control
- Organizer — granular permissions
- Member — member features
- Guest — public information only

## Privacy
Member profiles, participation data, and the gallery are private to logged-in members unless explicitly designed otherwise. Security must be enforced by the backend, not merely by hiding UI controls.

## Cost principle
No paid service should be an essential single point of failure. Data and application code must remain portable.
